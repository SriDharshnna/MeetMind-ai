# MeetMind AI 🤖

### Agentic AI-Powered Meeting Intelligence & Action Management System

## 📌 About the Project

MeetMind AI is an intelligent meeting management platform designed to help organizations manage meeting records, track responsibilities, monitor deadlines, and ensure that decisions are followed through.

Using Agentic AI, the platform transforms meeting discussions into actionable tasks and continuously monitors outstanding commitments.

## 🎯 Problem We Solve

- Scattered meeting minutes and notes.
- Forgotten employee commitments.
- Difficulty tracking overdue tasks.
- Repeated discussions across meetings.
- Lack of visibility into decisions and responsibilities.

## ✨ Key Features

- AI-powered Minutes of Meeting generation.
- Automatic action item extraction.
- Employee responsibility and deadline tracking.
- Overdue task monitoring.
- Centralized decision tracking.
- Cross-meeting topic detection.
- Intelligent follow-up agenda generation.

## 🤖 Agentic AI Architecture

1. Meeting Analysis Agent
2. Task Management Agent
3. Monitoring Agent
4. Follow-up Agent

## 🛠️ Technology Stack

- Frontend: React.js, Vite, CSS
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- AI: Google Gemini API
- Integration: REST APIs

## 🚀 Project Status

Currently under development. The application is being developed incrementally, module by module.

## 🎯 Objective

To improve organizational productivity, accountability, and meeting effectiveness through Agentic AI.
